# KLight IPTV

Daily merged playlist of publicly listed free channels, grouped by field in Arabic.

Playlist: `https://raw.githubusercontent.com/ALjasme/klight-iptv/main/playlist.m3u`

Sources: [iptv-org](https://github.com/iptv-org/iptv) (Kuwait, Arabic, Saudi Arabia, Iraq, Algeria), Apsattv (Xumo) [Free-TV](https://github.com/Free-TV/IPTV) and [world_ip_tv](https://github.com/Romaxa55/world_ip_tv) (only channels checked to play from Kuwait). This repository only re-groups their public links and hosts no video. It is not meant for paid or encrypted channels. Links in `unplayable.txt` failed from Kuwait and are left out.
